# Jump! The Minigame

**Jump! The Minigame** is a Scratch game developed by **roundkim** and **willowtreeby**.

## 🎮 About the Game

The game consists of **6 stages**, each with its own challenges, mechanics, and level design.

### Stage Overview

| Developer        | Stages                    |
| ---------------- | ------------------------- |
| **roundkim**     | Stage 3, Stage 5, Stage 6 |
| **willowtreeby** | Stage 1, Stage 2, Stage 4 |
